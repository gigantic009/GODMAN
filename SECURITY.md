# Security Policy

## Scope
GODMAN is a cross-platform diagnostics and defensive cybersecurity assistant, currently prioritizing Windows while expanding to Linux and macOS. Security reports concerning GODMAN, its dependencies, build/release process or privacy boundaries are welcome.

## Reporting
Please report vulnerabilities privately to the repository maintainer through GitHub's private vulnerability reporting feature, if enabled. If it is not enabled, contact the maintainer through a verified private channel before publishing details. Do not put exploit details, secrets, personal data or sensitive logs in public issues.

Include a concise description, affected version/commit, reproduction steps in an authorized local environment, impact and suggested mitigation if available.

## Response expectations
This project is maintained on a best-effort basis. A report is not guaranteed an immediate response or fixed timeline. The maintainer will assess, reproduce safely, prioritize, develop a fix and publish an advisory when appropriate.

## Supported versions
Until formal release versions and support windows are established, the latest mainline development version is the only version presumed to receive fixes.

## Safe testing
Test only GODMAN and systems you own or are explicitly authorized to assess. Do not conduct destructive, persistent or third-party tests.
